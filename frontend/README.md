# URL Shortener Frontend

This React application uses Vite and connects to the Spring Boot backend at `http://localhost:8080`.

For the complete project setup, API details, and backend instructions, see the [project README](../README.md).

## Run locally

Requirements: Node.js and npm.

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`). Start the backend separately before shortening or following URLs.
